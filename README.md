The ReLacks Producer Engine is an interactive, web-based algorithmic music generator designed to bridge structural engineering logic with music theory and sound synthesis. Built specifically for Jazzhop, Neo-Soul, and Lo-Fi production workflows, it proceduralizes complex jazz chord voicings and syncopated hip-hop rhythms into real-time audio and visual feedback.

⚙️Key Features

Dynamic Web Audio Synthesis: Synthesizes polyphonic jazz voicings (7ths, 9ths, 11ths, 13ths, shell voicings) and customizable drum patterns (kick, snare, hi-hats) on the fly using the browser's Web Audio API.
Full Key Signature Transposition: Real-time dynamic transposition across all 12 musical keys (C,C♯,D,…,B) with accurate frequency recalculation.
2.5-Octave Piano Visualizer: Interactive keyboard visualizer highlighting live note positions across MIDI ranges 48 through 79 (C3to G5).

Genre & Preset Selector: 
Instantly tweak tempo, swinging drum grids, and chord progressions across multiple genre presets including Lo-Fi Jazzhop, Neo-Soul, Bossa Nova, and Dark Trap.

Embedded Python DSP & CLI Showcase: 
Features a built-in terminal simulator and tabbed code viewer demonstrating Python logic for scale definitions, voice leading, and MIDI file exporting.

Industrial Red Aesthetic: 
Custom UI theme featuring pitch-black backgrounds, dark crimson accents, blueprint grid overlays, and technical dials.

🛠️ Built With

Frontend: HTML5, CSS3 Grid/Flexbox, ES6+ JavaScript

Audio Engine: Native Web Audio API (Oscillators, Gain Nodes, Noise Generators)

Design System: Custom Dark Red/Black Industrial Theme (#070709 / #7f1d1d)
